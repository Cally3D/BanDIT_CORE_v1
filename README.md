# BanD’IT CORE v1

Behavioural and Anomaly Detection Intelligence System for Lagos Island

## Overview

BanD’IT CORE v1 is a geospatial intelligence system designed to detect anomalies in the built environment of Lagos Island.

## Objectives

- Define baseline urban patterns
- Detect spatial anomalies
- Predict urban development risks
- Provide temporal visualisation insights

## Workflow

QGIS → Python → QGIS
